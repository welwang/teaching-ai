# 簡報修改記錄

系統自動記錄簡報內容與版面的修改，供後續分析教學品質、修改原因與模型效果。

- 全系統：`data/workflow-v2/deck-changes/YYYY-MM.jsonl`，按 UTC 月份分檔，保留全部月份。
- 單份教材：`data/workflow-v2/jobs/<任務ID>/changes.jsonl`。
- 介面：在「系統與紀錄」選範圍，展開「簡報修改記錄（分析用）」下載。

每筆包含 `schema_version`、唯一 `change_id`、UTC 時間、任務 ID、操作者、動作、教材、年級、科目、模型、教學提示詞指紋、前後內容與 SHA-256，以及 JSON Pointer 格式的欄位差異（新增／移除／替換）；按修改類型另保存父任務 ID、階段、頁碼與修改原因。

記錄涵蓋大綱確認、單次教學提示詞、單頁修改請求與實際結果、系統審核與修正、最終內容優化（含接受與退回的建議）、生成版面與使用者重新排版。相同內容重複寫入不另產生修改事件，進度刷新也不記作內容修改。

修改記錄與運行紀錄分開保存，清除運行紀錄不影響修改歷史。全系統月檔持續保留，即使某份教材被移至回收區，仍可依任務 ID 追溯。這些檔案只保存在本機。

用於分析的欄位示例：依 `actor` 區分使用者與系統；依 `changes[].path` 統計常被修改的欄位；依 `reason`、`instruction`、`stage` 與 `model` 分析重製與修正原因；用 `parent_job` 追蹤同一份教材的修訂鏈。記錄啟用後的新修改會自動納入。
