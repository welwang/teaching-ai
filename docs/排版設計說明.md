# 控制台排版與美化原則

更新：2026-10-13。以下五條原則適用於所有控制台頁面與後續調整。

1. **SpaceX 風格優先**：克制、精準，呈現任務控制室的資訊層級。靠留白、對齊與比例建立版面；不使用裝飾插圖、背景網格、漸層或陰影。
2. **圓潤柔和**：面板圓角 24 px、次要區塊 18 px、輸入框 12 px；按鈕採膠囊形。細線分區，不使用厚重方框。
3. **配色可切換，狀態清楚**：精簡為航太白（預設）、軌道黑、暖紙米、霧森綠、暮紫灰五種。白黑明暗差異明顯，暖米、森林綠與暮紫使用較清楚的背景色相，避免大量相近的淺色選項。所有表單、面板、按鈕與選單共用主題配色；強調色用於狀態、焦點與選取，不作背景裝飾。已移除的配色與舊版設定自動對應最接近的保留選項，保留字級與減少動畫設定；已開啟的網頁工作階段也會自動遷移。
4. **數字當主角**：完成度與預估剩餘時間使用大字，標籤較小但不低於 16 px。每區只有一個主要讀值，數字使用等寬字型。估算與實測數據清楚標示，無資料時不捏造數字。
5. **動畫平順而克制**：一般操作回饋維持 150–300 ms；依使用者要求，監控數值、指針、弧線與進度使用 600 ms 緩動，目前階段與即時狀態輕柔脈動，進行中的進度條有低對比流動光帶。尊重系統與介面的減少動畫選項；暫停或完成時停止持續動畫。所有可見文字至少 16 px、主要互動範圍至少 44 px；所有主題文字對比至少 4.5:1。

## 目前版面

- 頂端固定列：名稱與「顯示」選單，包含配色風格、字體大小與減少動畫。
- 內容置中，最大寬度 1240 px；大螢幕保留兩側空間，手機以必要內距排成單欄。外框可調整，但既有監控、控制與維護功能全部保留。
- 主監控採發射監控邏輯：狀態列、完成度與顯卡負載讀值、中央 T+ 計時與目前任務、實際七個任務階段、最新事件及需留意事項。縮小過大的時鐘與儀表，監控區高度依內容調整；窄螢幕保留讀值並重新排列。
- 監控操作提供暫停、續作與停止服務入口；會中斷服務的操作保留原有確認流程。
- 遙測詳情預設收合，固定高度並可內部捲動：生成速度、顯存、詞元、服務狀態、更早事件與維護用技術統計。主監控已顯示的數字不重複列出。
- 三個分頁使用水平導覽；桌面製作區與確認摘要採 7：3 雙欄，窄螢幕改為單欄。
- 教學提示詞可在製作區直接編輯，僅存入此次提交的任務。任務提交成功後立即還原預設，切換教材或年級科目也重新載入適用的預設；修改不寫入系統提示詞庫。可還原預設或下載本次版本，重試同一任務仍使用該任務已保存的提示詞。
- 階段進度線採圓角軌道，已完成區段與目前階段清楚區分；教材卡片進度條加厚至 6 px、使用膠囊圓角，更新動畫 600 ms，減少動畫時關閉。
- 空白、待命、進行中、暫停與異常狀態依實際資料呈現；更新監控時不重設輸入或捲動位置。

## 實作與驗證

正式入口 `app_v2.py` 呼叫 `workflow_v2/panel.py`。樣式與五種配色在 `workflow_v2/panel_style.py`，監控 HTML 在 `workflow_v2/panel_view.py`，監控資料由 `workflow_v2/console_state.py` 提供。

正式入口使用 AppTest 驗證全部五種配色的切換、保存、設定遷移、監控控制、技術統計與三個分頁。配色測試檢查正文及次要文字對比至少 7:1、狀態及按鈕文字至少 4.5:1。版面變更另以實際瀏覽器檢查桌面和窄螢幕的溢出、可讀性及操作入口。
