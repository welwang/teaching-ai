# 教材簡報工作室 v1.0.0

發布日期：2026-10-13。

首個 GitHub 正式版本，提供 Windows 本機教材製作、任務監控、修改分析與原始碼。

## 交付內容

- 可編輯 PPTX、PDF、教師備課稿，以及可選學習單與教師解答。
- 國小四年級至國中三年級、國語／數學／英語，8～50 頁教材。
- 來源、規劃、編寫、審核、排版、預覽和最後發布七階段。
- 大綱確認、單次教學提示詞、人工編輯與單頁重製。
- 完成度、T+、GPU、階段節點、製作總時長、服務與事件監控。
- 五種配色、字級與減少動畫設定。
- 修改前後內容、欄位差異、原因與修訂關係的 JSONL。
- 原生 PowerPoint 排版、內容與版面 QA、本機模型與蒸餾工具。

## 本次整理

- 移除停止使用的控制台、程式備份與開發暫存。
- 正式控制台的五種配色集中於現行樣式模組。
- 精簡冗長、重複註釋，保留必要說明。
- 新增詳細 README、架構圖、狀態機、部署和操作指南。
- 修正過時的模板、介面、模型與停止操作描述。
- 加入設定範本、Git 忽略規則與文字換行規則。
- 安裝包使用可攜設定，附離線文件、清單、版本資訊與校驗檔。

## 下載

| 資產 | 用途 |
| --- | --- |
| `TeachingAI-Installer-v1.0.0.zip` | Windows 安裝包，解壓縮後執行 `installer/Install-TeachingAI.cmd` |
| `TeachingAI-Installer-v1.0.0.zip.sha256` | SHA-256 校驗值 |
| GitHub 原始碼壓縮檔 | 程式、測試與開發文件 |

不包含模型、教材庫、成果與個人設定。Python 依賴首次啟動時準備；本機模型和 LibreOffice 另行配置。

## 驗證

- 發布前完整回歸基準：534 項測試。
- 驗證正式入口、配色、提示詞、內容 QA、修訂、紀錄與恢復。
- 安裝包檢查必要檔案、可攜設定、清單、憑證排除和 SHA-256。
- 架構與操作文件檢查本機連結及目前模組名稱。

新主機的 Python、GPU、模型、LibreOffice 和第一次生成仍需依 [安裝部署指南](https://github.com/welwang/teaching-ai/blob/v1.0.0/docs/安裝與部署.md)驗收。本次不宣稱已實測所有硬體或在全新主機完成端到端安裝。

## 使用限制

- 主要交付 Windows x64 本機版本。
- 模型內容、算式、題意與解答仍需教師確認；警示保留於報告。
- 速度依來源、模型、硬體和圖片需求而變。
- 線上圖片使用網路搜尋，來源與授權保存於任務資料。
- 不提供雲端多租戶、跨主機客服 App 串接或模型權重包。
