《簡報通用優化準則》
適用範圍：教學簡報、報告簡報、研究簡報、企劃簡報、課程簡報、產品簡報、活動簡報、專題簡報等各類內容。
限制原則：在「不得更改原有排版」的前提下進行優化。不得任意改變頁面尺寸、版型、物件位置、文字框位置、圖片位置、頁面數量與整體視覺架構。

一、核心優化原則
1. 保留原有排版
   - 不移動既有文字框、圖片、圖表、圖示、頁碼、標題區與裝飾元素。
   - 不更換整套版型。
   - 不新增會破壞原構圖的大型物件。
   - 優化以「內容、文字、層級、格式、資訊邏輯」為主。

2. 一頁一個主要重點
   - 每頁只聚焦一個核心訊息。
   - 若同一頁有多個觀念，需明確分成主次層級。
   - 標題應能直接說明該頁要傳達的內容。

3. 先修正內容，再美化文字
   - 優先檢查錯字、錯誤數據、錯誤公式、重複內容與錯置內容。
   - 確認內容正確後，再進行精簡與美化。
   - 不可為了縮短文字而改變原意。

4. 保留原本邏輯，但讓閱讀順序更清楚
   - 原有頁面順序原則上不變。
   - 每頁內容應有清楚的閱讀順序：
     標題 → 核心內容 → 補充 → 結論／行動。

二、標題優化
1. 標題要能回答「這頁在講什麼」。
2. 避免過長標題，盡量控制在一行內。
3. 避免使用模糊標題，例如：
   「介紹」
   「內容」
   「說明」
   「相關資料」
4. 改成具體標題，例如：
   「研究目的」
   「市場規模變化」
   「問題發生原因」
   「三項核心成果」
5. 同一份簡報的標題語氣要一致。
6. 不任意更改標題位置與字級層級。

三、內文優化
1. 刪除不必要贅詞。
2. 一句只表達一個主要概念。
3. 長句拆成短句。
4. 長段落拆成 2～5 個重點。
5. 避免大量完整文章直接貼入簡報。
6. 保留重要名詞、數據、結論與必要背景。
7. 不改變原本意思。
8. 若文字框空間有限，優先縮短文字，而不是縮到難以閱讀的字級。

四、資訊層級優化
每頁內容建議分成三層：

第一層：核心訊息
- 標題
- 結論
- 最重要數字

第二層：主要說明
- 關鍵原因
- 核心步驟
- 主要證據

第三層：補充資訊
- 備註
- 詳細說明
- 資料來源
- 次要條件

優化時需確保：
- 第一眼能看到第一層。
- 第二眼才閱讀第二層。
- 第三層不應搶過主要內容。

五、關鍵資訊強調
1. 每頁最多強調 1～3 個重點。
2. 可利用原本已有的：
   - 粗體
   - 字級差異
   - 原配色中的強調色
   - 底線
   - 色塊
3. 不要整頁全部加粗。
4. 不要同時使用太多不同顏色。
5. 強調對象優先順序：
   - 結論
   - 關鍵數字
   - 關鍵詞
   - 行動項目

六、數字與資料優化
1. 統一數字格式。
2. 同類數據保留相同小數位。
3. 百分比格式統一。
4. 金額單位統一。
5. 日期格式統一。
6. 大數字可使用：
   千、萬、百萬、億
   或 K、M、B
   但同一份簡報不可混用。
7. 數字後應清楚標示單位。
8. 重要數據應搭配一句解讀，而不是只放數字。
9. 不確定的數據不可自行補齊或猜測。

七、條列內容優化
1. 同一組條列句型保持一致。
2. 每點盡量控制在 1～2 行。
3. 每頁條列建議不超過 5～6 點。
4. 條列內容按照以下方式排序：
   - 重要性
   - 時間順序
   - 流程順序
   - 因果順序
5. 避免每一點都寫成完整長段落。

八、圖表優化
在不改變圖表位置的前提下：
1. 確認圖表標題明確。
2. 軸標題與單位完整。
3. 圖例名稱清楚。
4. 刪除無意義的小數位。
5. 強調最重要的數據。
6. 不讓次要格線、邊框比數據更醒目。
7. 圖表旁應有一句重點解讀。
8. 避免只放圖表卻沒有結論。

九、表格優化
1. 不改變表格整體位置。
2. 刪除不必要文字。
3. 欄位名稱簡短。
4. 數字對齊。
5. 同類資料格式一致。
6. 最重要欄位或列可使用原配色強調。
7. 表格過密時，優先縮短文字，而不是縮小字級。
8. 一個表格應有明確閱讀目的。

十、圖片優化
1. 圖片必須與本頁內容直接相關。
2. 不使用純裝飾、無資訊價值的圖片搶畫面。
3. 確認圖片清晰。
4. 圖片旁的文字應說明「為什麼要看這張圖」。
5. 不隨意拉伸圖片造成變形。
6. 若原本圖片與內容不符，可更換，但保持原圖片框位置與大小。

十一、流程頁優化
適用於步驟、方法、流程、時間軸。
1. 每一步驟使用相同句型。
2. 步驟名稱簡短。
3. 清楚標示先後順序。
4. 每一步只寫必要資訊。
5. 若有「輸入 → 過程 → 輸出」，應明確呈現。
6. 不把詳細說明全部塞入流程框。

十二、比較頁優化
1. 左右比較項目順序一致。
2. 同一列比較相同面向。
3. 不可一邊寫功能、一邊寫優缺點。
4. 比較項目數量盡量一致。
5. 最後要有一個清楚的比較結論。
6. 不改變原左右或多欄布局。

十三、問題與解決方案頁
建議邏輯：
問題 → 原因 → 影響 → 解法 → 預期成果

優化原則：
1. 問題描述具體。
2. 原因與結果不要混在一起。
3. 解法必須對應前面的問題。
4. 最後要說明改善後會得到什麼。

十四、研究／報告型簡報
建議內容邏輯：
背景 → 問題 → 目的 → 方法 → 結果 → 分析 → 結論

優化重點：
1. 研究問題明確。
2. 方法不要寫成過長敘述。
3. 結果與解釋分開。
4. 結論必須來自前面的結果。
5. 限制與未來方向清楚區分。

十五、教學型簡報
建議邏輯：
情境 → 概念 → 示範 → 練習 → 回饋 → 總結

優化重點：
1. 每頁只教一個概念。
2. 先理解，再計算。
3. 範例步驟一致。
4. 練習與解答分開。
5. 不在正式解答頁保留錯誤計算。
6. 學生應能從頁面看出「現在學什麼」。

十六、企劃／商業型簡報
建議邏輯：
現況 → 問題 → 機會 → 方案 → 執行 → 成本 → 效益 → 下一步

優化重點：
1. 結論先行。
2. 數字比形容詞重要。
3. 每個方案都要對應問題。
4. 行動項目要具體。
5. 最後一頁應明確說明下一步。

十七、前後頁銜接
1. 前一頁提出問題，下一頁回答。
2. 前一頁介紹概念，下一頁示範。
3. 前一頁顯示數據，下一頁解讀。
4. 避免連續多頁內容完全重複。
5. 若版型限制必須重複，則讓每頁功能不同。

十八、重複頁面處理
若兩頁版型與內容高度相似：
- 第一頁可作為題目／問題。
- 第二頁作為解答／分析。
- 或第一頁作為總覽，第二頁作為細節。
不可只是複製相同內容。

十九、錯誤內容檢查
每份簡報都必須檢查：
□ 錯字
□ 標點
□ 數據
□ 日期
□ 人名
□ 單位
□ 公式
□ 算式
□ 百分比
□ 圖表數字
□ 頁面標題與內容是否一致
□ 是否有複製貼上殘留文字
□ 是否有內容重複
□ 是否有前後矛盾

二十、文字格式一致性
1. 中文標點一致。
2. 英文大小寫一致。
3. 中文與英文之間的空格規則一致。
4. 日期格式一致。
5. 數字格式一致。
6. 單位格式一致。
7. 專有名詞第一次出現時使用完整名稱。
8. 同一概念全篇使用相同名稱。

二十一、禁止的優化方式
在不得更改排版的要求下，不可：
1. 任意移動物件。
2. 任意改變圖片大小。
3. 任意調整文字框位置。
4. 任意新增大型圖形。
5. 任意改變頁面比例。
6. 任意更換整體主題。
7. 大量改字體造成版面變形。
8. 為塞入更多文字而把字縮得太小。
9. 為追求美觀而刪除重要內容。
10. 改變原簡報的核心意思。

二十二、通用優化流程
步驟 1：完整閱讀整份簡報。
步驟 2：確認簡報目的與主要受眾。
步驟 3：標記錯誤、重複、錯置與不完整內容。
步驟 4：修正內容正確性。
步驟 5：逐頁確認標題與內容一致。
步驟 6：刪除贅詞與長句。
步驟 7：整理資訊層級。
步驟 8：統一術語、數字、日期、單位與格式。
步驟 9：強調每頁 1～3 個最重要資訊。
步驟 10：確認圖表與圖片是否真的支持內容。
步驟 11：檢查前後頁邏輯。
步驟 12：檢查是否有文字溢出或可讀性下降。
步驟 13：播放整份簡報再次檢查。
步驟 14：確認排版、頁數與物件位置皆未改變。

二十三、每頁快速檢查法
每一頁都問以下 7 個問題：

1. 這頁要傳達什麼？
2. 標題是否直接說明重點？
3. 觀眾 3 秒內能否找到核心資訊？
4. 有沒有可以刪掉的文字？
5. 關鍵數字／結論是否突出？
6. 這頁與前後頁是否有邏輯關係？
7. 是否在不改排版的情況下已經達到最佳可讀性？

二十四、整份簡報最終檢查清單
□ 原排版保持不變
□ 原頁數保持不變
□ 原物件位置保持不變
□ 每頁只有一個主要重點
□ 標題清楚
□ 文字精簡
□ 關鍵字有層級
□ 數字與單位一致
□ 圖表有結論
□ 圖片與內容相關
□ 沒有錯置文字
□ 沒有明顯錯誤
□ 沒有不必要重複
□ 前後頁邏輯順暢
□ 所有頁面都能快速理解
□ 沒有文字超出原本框架
□ 不因優化而改變原意

二十五、一句話版本
在不改變原有排版的前提下，優化簡報的核心就是：
「修正錯誤、刪除贅詞、突出重點、統一格式、整理邏輯，讓觀眾更快理解原本想表達的內容。」
