# 教學提示詞研究與轉換紀錄

研究整理日期：2026-10-02

## 來源與設計的界線

課綱定義學習階段或數學年級內容；本檔的逐年鷹架、頁面容量與活動順序是系統教學設計建議，不是官方固定教法、學期單元表或對每位學生能力的斷言。

國語與英語主要依學習階段安排理解與表達；數學參考官方年級內容，但實際版本與學期以主教材為準。逐年活動、文字容量和鷹架是本系統的設計配置，不能被描述成官方唯一教法或所有孩子的能力上限。讀題線索、算式、文本證據與完整解答優先於字數建議。

## 由研究轉成可執行要求

| 原則 | 系統要求 |
| --- | --- |
| 示範與練習交替 | 示範來源支持的方法，接相近學生任務及可核對答案 |
| 具體與抽象連結 | 國小先觀察或操作，再連圖、詞語或符號；國中保留前提與推理 |
| 主動提取與解釋 | 先讓學生作答，再核對；高難度增加依據、方法選擇或遷移 |
| 理解與表達 | 國語有文本線索，英語有溝通用途，數學有可追溯的表示與演算 |
| 差異化支援 | 低難度提供可用線索，中難度逐步移除，高難度不超出已教範圍 |

## 網路來源

### 教育部十二年國教國語文課程綱要（國教院發布檔）

[教育部十二年國教國語文課程綱要（國教院發布檔）](https://www.naer.edu.tw/upload/1/16/doc/806/十二年國民基本教育課程綱要國民中小學暨普通型高級中等學校(語文領域─國語文).pdf)

參考位置：學習表現：第二至第四學習階段的聆聽、說話、閱讀、寫作。語文活動兼顧理解與表達，隨學習階段增加文本分析與有依據的觀點表達。

### 國教院國語文課程手冊（定稿版）

[國教院國語文課程手冊（定稿版）](https://www.naer.edu.tw/upload/1/16/doc/2080/語文領域-國語文課程手冊(定稿版).pdf)

參考位置：教學與評量示例。參考文本取材、教學策略及評量設計；不複製示例課文與題目。

### 教育部數學領域課綱英譯（新北市英語教學資源中心刊載）

[教育部數學領域課綱英譯（新北市英語教學資源中心刊載）](https://englishcenter.ntpc.edu.tw/uploads/16767043725953AafXiFc.pdf)

參考位置：Learning Content，Grade 4 至 Grade 9；PDF第50–90頁附近。數學內容有年級編碼，具體操作、表示、運算與理由需連結；年級內容不等同各版本的學期順序。

### 教育部十二年國教英語文課程綱要（發布版）

[教育部十二年國教英語文課程綱要（發布版）](https://www.naer.edu.tw/upload/1/16/doc/812/(發布版)國民中小學暨普通型高級中等學校-語文領域-英語文課程綱要.pdf)

參考位置：課程目標、學習表現與實施要點。以聽說讀寫及日常溝通為核心；依第二、第三、第四學習階段調整語言任務。

### 國教院英語文課程手冊

[國教院英語文課程手冊](https://www.naer.edu.tw/upload/1/16/doc/2075/語文領域-英語文課程手冊.pdf)

參考位置：教學案例與差異化活動。從有用途的語境、詞彙例句及學生參與設計活動，而非只列文法名詞。

### IES：Organizing Instruction and Study to Improve Student Learning

[IES：Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)

參考位置：Recommendations 2、3、4、5b、7。交替示範與練習，連結圖像與文字、具體與抽象表示，用提取練習及解釋性提問促進理解。

### IES：Improving Adolescent Literacy

[IES：Improving Adolescent Literacy](https://ies.ed.gov/ncee/wwc/PracticeGuide/8)

參考位置：Recommendations 1–4，適用5–12年級。明確示範詞彙與理解策略，安排有內容的文本討論；不把此英語閱讀研究當成臺灣國語年級內容表。

### IES：Teaching Academic Content and Literacy to English Learners

[IES：Teaching Academic Content and Literacy to English Learners](https://ies.ed.gov/ncee/wwc/PracticeGuide/19)

參考位置：Recommendations 1–3，K–8。提供反覆使用詞彙、結合口語與書寫的結構化任務；美國英語學習者情境與臺灣外語課不同，僅借用活動設計原則。

## 維護方式
