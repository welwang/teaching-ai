# 18 份年齡適配教學提示詞

涵蓋國小四、五、六年級與國中一、二、三年級的國語、數學、英語。每份完整規格均含先備檢核、示範、學生任務、低中高分級、迷思、配圖、評量及研究來源。

系統依年級與科目自動選擇，按大綱、逐頁編寫、審核、學習單、選版用途注入相關部分；不把 18 份一起送給模型，也不把網路教學建議當成本次單元內容。

國語、英語的介面 stage=計算 代表「示範與練習」，學生畫面不使用計算階段名稱。英語保留正確的英文課文、例句及學生回答，教師指令與解說使用繁體中文。

| 年級 | 科目 | 完整提示詞 | 教學重心 |
| --- | --- | --- | --- |
| 國小四年級 | 國語 | [g4-chinese.md](g4-chinese.md) | 以短摘句、人物事件和清楚語境建立閱讀理解。依本課文字教詞義、事件順序或簡單主旨；不要把課文變成沒有文字依據的品格結論。 |
| 國小四年級 | 數學 | [g4-math.md](g4-math.md) | 以看得見的量與圖建立方法。只在主教材涉及時使用位值、四則、分數、小數、量測或圖形；位值不先教代數，等分不先教通分公式。 |
| 國小四年級 | 英語 | [g4-english.md](g4-english.md) | 以看懂、聽懂和敢用一個短句為起點。只選本課詞彙、語音或句型；先用熟悉場景說明用途，不要求背長文法定義或自由長對話。 |
| 國小五年級 | 國語 | [g5-chinese.md](g5-chinese.md) | 從段落重點走向段落關係。依文本類型教事件因果、說明順序、詩歌意象或簡單觀點；摘句支援分析，不羅列完整修辭百科。 |
| 國小五年級 | 數學 | [g5-math.md](g5-math.md) | 從操作與圖表示逐步走向規則。主教材涉及因數倍數、分數、小數或面積體積時，先說清楚量的關係；不要把所有單元都轉為背公式。 |
| 國小五年級 | 英語 | [g5-english.md](g5-english.md) | 把詞與句連到簡短對話和用途。依本課語言功能完成詢問、描述或回應，閱讀先找明確資訊；不突然增加未教時態或句型。 |
| 國小六年級 | 國語 | [g6-chinese.md](g6-chinese.md) | 逐步形成有根據的整篇理解。依本課訓練主旨、人物變化、表達效果、說明結構或簡單論點，並連結相關經驗；不把所有文字都教成單一人生道理。 |
| 國小六年級 | 數學 | [g6-math.md](g6-math.md) | 把具體表示、運算與解釋連在一起。僅在來源涉及時處理質因數、分數小數運算、比與速率、幾何或資料；未教方程式與國中符號不拿來捷徑解題。 |
| 國小六年級 | 英語 | [g6-english.md](g6-english.md) | 增加獨立使用句型及短文字理解，仍以已教詞句為界。將詞彙、句型與溝通目的連結，來源若有短寫作則由一句到連貫數句，不預設能自由寫長文。 |
| 國中一年級 | 國語 | [g7-chinese.md](g7-chinese.md) | 銜接國中國文的文本分析。依來源認識敘事、抒情、說明或文言語句；先懂詞句與段意，再談結構、觀點或表達效果，語氣尊重且不幼稚。 |
| 國中一年級 | 數學 | [g7-math.md](g7-math.md) | 重視從具體語意到符號的國小國中銜接。主教材若教負數、未知數、方程式、比例或座標，先解釋符號代表的量及關係，不能只背移項規則。 |
| 國中一年級 | 英語 | [g7-english.md](g7-english.md) | 由國小詞句銜接到國中句型與短篇閱讀。先解釋語句用途與結構，逐步使用本課語法，不預設每位學生已記住所有國小詞彙。 |
| 國中二年級 | 國語 | [g8-chinese.md](g8-chinese.md) | 增加跨段整合和表達效果的比較。主教材有多種觀點或議論時才分析主張與理由；主教材有文言時才增加語境判讀，不能普遍套論說文格式。 |
| 國中二年級 | 數學 | [g8-math.md](g8-math.md) | 支援有前提的多步推理。來源若涉及根式、式的運算、方程式、幾何或函式，先說明條件與中間目標，再解釋為何選用該性質。 |
| 國中二年級 | 英語 | [g8-english.md](g8-english.md) | 連結已教語法與較有關係的短文字。來源有時序、因果或描述關係時，讓學生追蹤資訊與句型功能，不只做脫離語境的填空。 |
| 國中三年級 | 國語 | [g9-chinese.md](g9-chinese.md) | 訓練基於文字的判斷、比較與遷移。可整合本課已教的篇章結構、語境與表達手法；不把深度等同艱深評論術語，也不把每課變會考選擇題。 |
| 國中三年級 | 數學 | [g9-math.md](g9-math.md) | 整合與選策略仍限於主教材及確認的先備。來源中的比例、相似、圓、二次關係或機率等任務，先分類條件，再選方法，不把整課改成會考題海。 |
| 國中三年級 | 英語 | [g9-english.md](g9-english.md) | 以理解、整合與有目的表達鞏固國中已教內容。來源提供多資訊或觀點時才練推論與比較，不用生僻字和長難句模擬所謂高階英語。 |
